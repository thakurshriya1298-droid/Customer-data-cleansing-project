# Customer Data Cleansing Project

## Project Overview
This project demonstrates a practical data-cleaning workflow for a customer dataset. The raw data contains duplicate records, inconsistent capitalization and spacing, inconsistent dates, missing contact details, and an invalid email address.

## Tools Used
- Python / Pandas
- Excel
- GitHub
- Data quality validation

## Cleaning Tasks
1. Removed duplicate customer records.
2. Standardized customer names.
3. Trimmed extra spaces.
4. Converted emails to lowercase.
5. Removed spaces/non-numeric characters from phone numbers.
6. Standardized city and state names.
7. Converted signup dates to a consistent date format.
8. Created email and phone validation flags.
9. Identified missing email and phone values.
10. Created a data-quality summary.

## Files
- `raw_customer_data.csv` — original messy dataset
- `cleaned_customer_data.csv` — cleaned dataset
- `data_quality_summary.csv` — before/after quality metrics
- `customer_data_cleansing.xlsx` — Excel workbook containing raw data, cleaned data and summary

## Key Outcome
The project shows how raw operational/customer data can be transformed into a cleaner, more consistent dataset suitable for reporting and analysis.
